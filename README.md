# 🍜 ViveRoulette - 飲食店ルーレットアプリ

> 「今日何食べよう？」を解決してくれるWebアプリです。
> ホットペッパーグルメAPIを利用して、入力した条件からランダムに1件の飲食店を提案します。

---

## 📋 アプリの概要

都道府県・ジャンル・予算・こだわり条件などを入力してルーレットを回すと、
条件に合った飲食店の中からランダムで1件を選んで表示してくれます。

- **お店の写真・店名・住所・電話番号・営業時間**を一覧表示
- **ホットペッパーの店舗詳細ページへのリンク**付き
- スマホから**電話番号をタップして直接発信**可能
- 気に入らなければ**「もう一度ルーレット！」**で同じ条件で再抽選

## 🚀 起動方法

### 必要な環境

- Java 21 以上
- インターネット接続（ホットペッパーグルメAPIへのアクセスが必要）

### 手順

```bash
# 1. リポジトリをクローン
git clone https://github.com/HelloRamen420/ViveRoulette.git
cd ViveRoulette/demo

# 2. アプリを起動（初回はライブラリのダウンロードが走るため少し時間がかかります）
./mvnw spring-boot:run
```

### アクセス方法

起動完了後、ブラウザで以下のURLを開いてください。

```
http://localhost:8080/RouletteDinner_home
```

## 🔍 主な機能

### 検索条件

| 条件 | 内容 |
|------|------|
| 都道府県 | 全47都道府県に対応（必須） |
| フリーワード | 市区町村や料理名など自由入力 |
| 料理ジャンル | 居酒屋・ラーメン・カフェ・和食など10ジャンル |
| ご予算目安 | ～1,500円〜5,001円〜 5段階 |

### こだわり条件（チェックボックス）

- 深夜営業あり
- 禁煙席あり
- 駐車場あり
- 個室あり
- WiFiあり
- お子様連れ歓迎
- カード利用可
- ランチあり

### 結果表示

- 店舗の大きな写真
- 店名・住所・電話番号（タップで発信）・営業時間
- ホットペッパー詳細ページへのリンクボタン
- 「もう一度ルーレット！」ボタン（条件はそのまま再抽選）
- 「条件を変える」「ホームに戻る」ボタン

## 💡 仕組み

1. ユーザーが条件を入力してフォームを送信
2. `HomeController` がリクエストを受け取り、`Restaurant` オブジェクトに検索条件をセット
3. `ManyControllers.urlMake()` が条件に応じたホットペッパーAPIのURLを構築
4. まず検索条件にヒットする**総件数を取得**し、その中からランダムな位置を決定
5. ランダムな1件の店舗データをAPIから取得し、結果画面に表示

> この方式により、人気店への偏りなく真にランダムな選択を実現しています！
